Human-AI Co-creation: LLMs, Contextual Hints, Performance

This repository accompanies the publication _“Human-AI Co-creation: LLMs, Contextual Hints, Performance”.  
It provides sample data and code for reproducing the experimental results.

## Contents
- Sample dataset
- Scripts for computing Cosine, Jaccard, Edit Distance, and Word Overlap similarities
- Sample outputs and plots

## Reproducibility
Due to copyright restrictions, only anonymized data samples are shared. Full data available upon request.
